# Admin Traceability Matrix

| SOW Admin Requirement     | UI Route Family                      | API Endpoint Family                                                                                      | Database Entities                                                                      | Permission                                                               | Required Tests                                                                               |
| ------------------------- | ------------------------------------ | -------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------- |
| Dashboard summaries       | `/admin`                             | `GET /api/v1/admin/dashboard`                                                                            | `Booking`, `Payment`, `StaffProfile`, `Review`                                         | `dashboard:view`, `reports:export`                                       | Empty state, permission denial, date filter, export bounds.                                  |
| Booking management        | `/admin/bookings`                    | `/api/v1/admin/bookings`                                                                                 | `Booking`, `BookingItem`, `BookingStatusHistory`, `StaffAssignment`, `ServiceStartOtp` | `bookings:view/create/update/assign/approve/delete`                      | State transitions, assignment transaction, double-booking denial, RBAC denial.               |
| Customer management       | `/admin/customers`                   | `/api/v1/admin/customers`                                                                                | `User`, `CustomerProfile`, `Address`, `Booking`, `Review`, `SupportTicket`             | `customers:view/update/export`                                           | Object access, search/filter, export permission, PII redaction.                              |
| Employee/staff management | `/admin/staff`                       | `/api/v1/admin/staff`                                                                                    | `User`, `StaffProfile`, `StaffSkill`, `StaffZone`, `StaffDocument`, `StaffSchedule`    | `staff:view/create/update/approve/delete`                                | Invite/status changes, document expiry, engagement classification only, no payroll behavior. |
| Catalogue                 | `/admin/catalogue`                   | `/api/v1/admin/categories`, `/api/v1/admin/services`                                                     | `Category`, `Service`, `ServiceImage`, `ServiceAddon`, `Skill`, `Zone`                 | `categories:*`, `services:*`                                             | Slug uniqueness, cycle/depth rejection, publish/archive, dependency-safe archive.            |
| Payments/invoices         | `/admin/payments`, `/admin/invoices` | `/api/v1/admin/payments`, `/api/v1/admin/refunds`, `/api/v1/admin/invoices`, `/api/v1/webhooks/razorpay` | `Payment`, `RefundRecord`, `Invoice`, `WebhookEvent`, `IdempotencyKey`                 | `payments:view/update`, `refunds:refund/approve`, `invoices:view/export` | Signature verification, idempotency, refund denial, no raw card data.                        |
| Reports                   | `/admin/reports`                     | `/api/v1/admin/reports/*`                                                                                | Source module entities plus export audit                                               | `reports:view/export`                                                    | Bounded ranges, permission denial, large export safety, audit entry.                         |
| Notifications             | `/admin/notifications`               | `/api/v1/admin/notifications/*`                                                                          | `NotificationTemplate`, `NotificationRule`, `NotificationDelivery`, `OutboxEvent`      | `notifications:view/create/update/delete/publish`                        | Provider unconfigured state, outbox retry, template validation.                              |
| Roles                     | `/admin/roles`                       | `/api/v1/admin/roles`, `/api/v1/admin/permissions`                                                       | `Role`, `Permission`, `UserRole`, `RolePermission`                                     | `roles:view/create/update/delete/manage_permissions`                     | Default deny, no self-promotion, no last-super-admin removal, system-role protection.        |
| Admin users               | `/admin/admin-users`                 | `/api/v1/admin/users`, `/api/v1/admin/invitations`                                                       | `User`, `AdminInvitation`, `Session`, `SecurityEvent`, `AuditLog`                      | `admin_users:view/create/update/delete`                                  | Invite flow, status changes, session revocation, throttling, audit.                          |
| Content                   | `/admin/content`                     | `/api/v1/admin/content`                                                                                  | `ContentPage`, `ContentRevision`, `MediaAsset`                                         | `content:view/create/update/publish/delete`                              | Sanitization, revision rollback, publish audit, no invented legal terms.                     |
| Contacts                  | `/admin/contacts`                    | `/api/v1/admin/contacts`                                                                                 | `ContactSubmission`, `ContactActivity`                                                 | `contacts:view/update/assign/export`                                     | Assignment permission, status changes, PII-safe logs, CSV permission.                        |
